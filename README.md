# Interactive Greeting Card Generator
## [✏️try here](https://butkii025.github.io/Card-generator/)
## 📖 Overview
The **Interactive Greeting Card Generator** is a simple web-based tool that allows users to create personalized greeting cards

## ✨ Features
- **Greeting Options**: Choose from *Happy Birthday*, *Happy Teacher’s Day*, *Happy Independence Day*, *Happy Republic Day*, or create a custom greeting.
- **Image Upload**: Add your own image to personalize the card.
- **Custom Message**: Write a personal message for the recipient.
- **Recipient Name**: Optionally include the recipient’s name.
- **Preview**: See the card before saving or sharing.

---

## 🛠️ Technologies Used
- **HTML5** for structure  
- **CSS3** for styling (dark theme)  
- **JavaScript** for dynamic preview  

---

## 🚀 Use
1. Open `index.html` in your browser.  
2. Select a greeting type or enter a custom one.  
3. Upload an image (optional).  
4. Enter your message and recipient’s name.  
5. Click **Generate** to preview the card.  
6. Save or share the card as needed.
